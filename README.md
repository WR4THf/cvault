<h3 align="center">TRANSFER · PAY · HOLD</h3>

<br><br>

CVault is an experimental, non-custodial open-source crypto wallet tailored specifically for Linux systems. The project combines a high-performance C++20 backend for secure core cryptography with a hardware-accelerated Qt 6 / QML frontend to deliver a fluid, modern user experience. By managing local keys securely and integrating modern visual enhancements like Liquid Glass shaders, CVault aims to provide a safe, lightweight, and visually striking gateway to the blockchain ecosystem.
